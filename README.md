## 🇬🇧 English

**Oxide Film** is a modern, cross-platform media aggregation application built with Flutter. It provides a unified interface to discover, track, and watch movies and TV shows from various sources.

### ✨ Features

- **Multi-Provider Support**: Seamlessly aggregate content from multiple sources (UAFlix, UaSerials, etc.).
- **Unified Library**: Keep track of your watch history and favorites in one place.
- **Cross-Platform**: Optimized for Android, Windows, and Web (beta).
- **Modern UI**: Sleek Material 3 design with dark mode and dynamic theming.
- **Advanced Player**: Built-in video player with quality selection, subtitles, and gesture controls.
- **Offline Support**: Cache metadata and history for offline access.
- **Account Sync**: Sync your progress across devices using PocketBase.

### 🚀 Getting Started

#### Prerequisites
- Flutter SDK (3.27+)
- Dart SDK (3.6+)
- Android Studio / VS Code

#### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/edhases/oxide_film.git
   cd oxide_film
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

### 🛠 Tech Stack

- **Framework**: [Flutter](https://flutter.dev/)
- **State Management**: Provider + GetIt
- **Navigation**: GoRouter
- **Backend**: PocketBase (Auth & Sync)
- **Local Database**: Hive / Isar
- **Video Player**: media_kit
